## Хочу

Полный рабочий текст темы 02: **«Индекс: как изменение попадает в коммит»** (`ru/02.html`) на
русском языке. Страница раскрывает механику staging area (индекса Git) как бинарного кэша дерева
проекта, объясняет три состояния файлов (modified, staged, committed), учит гранулярной сборке
коммитов через `git add` и `git add -p` (hunk staging), и даёт чёткую ментальную модель трёх
векторов сравнения через `git diff`, `git diff --staged` и `git diff HEAD`. Инженер любого уровня
(Noob, Pro, IGL) понимает, как устроен файл `.git/index` и почему коммит создаётся из индекса,
а не из рабочего каталога.

## Предикаты

Ровно три. Все три проверяются машиной без оценочных суждений.

1. **Страница `ru/02.html` написана до конца, и это подтверждает машина.**
   `grep -c 'Текст этого раздела ещё не написан' ru/02.html` даёт ровно `0`.
   Объём страницы в словах (`data-words`) составляет **не менее 1100 слов** (стандарт разборов
   тем серии devops-*).
   Соблюдена строгая двухуровневая нумерация: в навигаторе тема отмечена `<span class="num">2</span>`,
   все содержательные подразделы `<h2>` имеют последовательную нумерацию `N · Название`
   (кроме вступительного «Главная мысль страницы» и завершающего «Артефакты»).
   В тексте выдержана лестница мастерства Noob / Pro / IGL (In-Game Leader) и философия интересной
   игры со сложными техническими вызовами.

2. **Каждое утверждение об индексе и командах Git проверено запуском.**
   В манифест `tools/claims.tsv` добавлены проверяемые машиной утверждения об индексе
   (структура `.git/index`, команда `git ls-files --stage`, разница векторов `git diff` против
   `git diff --staged`, создание объекта tree напрямую из индекса через `git write-tree`).
   Манифест расширен не менее чем на 5 новых проверяемых утверждений.
   `./check.sh` выводит `[ ДА ] утверждения сайта` (все команды выполняются в изолированных
   `mktemp -d` каталогах с кодом возврата `0`).

3. **Дифф не выходит за границы задания, и полная проверка сайта зелёная.**
   `git diff --name-only` относительно начала задания содержит только: `ru/02.html`,
   `tools/claims.tsv`, сгенерированные блоки (`sitemap.xml`, метаданные страниц, индекс поиска
   `assets/search-*.js`), и файлы смены в `lessons/` (`step-2.md`, `record-2.md`).
   Полный проверочный контур `./check.sh` печатает `ЗЕЛЁНОЕ` (9 из 9 ДА).
