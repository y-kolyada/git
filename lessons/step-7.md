## Хочу

Полный рабочий текст темы 07: **«Отмена: restore, reset, revert, reflog»** (`ru/07.html`) на русском языке. Страница раскрывает системную классификацию операций отмены изменений на трех деревьях Git (рабочая копия, индекс и история коммитов), современный инструмент точечной отмены `git restore` (очистка рабочей копии, исключение из индекса `--staged`, восстановление из произвольного коммита `--source`), механику смещения указателей `git reset` во всех трех режимах (`--soft`, `--mixed`, `--hard`), безопасную отмену опубликованных коммитов через `git revert` (включая особенности отката коммитов слияния `-m 1`), а также универсальный механизм спасения `git reflog` и восстановимость любых зафиксированных объектов. Инженер любого уровня (Noob, Pro, IGL) осваивает точную ментальную карту отмены и обретает абсолютную уверенность в безопасности своих действий в Git.
